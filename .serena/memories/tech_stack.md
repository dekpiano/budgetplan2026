# Stack
- PHP project using CodeIgniter 4 framework (`codeigniter4/framework` `^4.0`).
- Supported PHP constraint in `composer.json`: `^7.4 || ^8.0`.
- Composer is the dependency/package manager; production autoloader optimization is enabled.
- PHPUnit `^9.1` is the configured development test framework; Faker and vfsStream are test dependencies.
- Application structure follows CI4 conventions: `app/Config`, `Controllers`, `Database`, `Filters`, `Helpers`, `Libraries`, `Language`, `Models`, `ThirdParty`, `Views`.
